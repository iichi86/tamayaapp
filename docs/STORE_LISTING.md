東京都中野区・新中野の「むさしの玉屋」の会員アプリです。
いつものご来店でスタンプをため、特典をご利用いただけます。

【会員証と来店スタンプ】
メールアドレスとパスワードで会員登録。生菓子・ギフト商品が対象の500円以上のお会計で、店舗スタッフが確認して1スタンプをお付けします。付与は同じ会員につき日本時間で1日1回までです。

【5スタンプで生菓子の特典】
5スタンプに達すると5個を使い、当日の対象商品からスタッフが選ぶ生菓子1つの特典を1枚発行します。有効期間は発行から90日間。交換時に追加購入は不要で、他の割引・クーポンとの併用も可能です。使用済み・期限切れの特典は利用できません。

【お知らせ・店舗情報】
お店からのお知らせ、住所、営業時間、基本定休日をご確認いただけます。

【機種変更・ログインの復旧】
同じメールアドレスでログインすれば、機種変更後も会員情報を引き継げます。パスワードを忘れた場合は、登録メールアドレスで再設定できます。

会員登録・アプリの利用は無料です。通信に必要な費用はお客様の負担となります。
スタンプ付与と特典の使用は、店頭でスタッフが確認して行います。

## Appのプライバシー申告用の整理

これは実装と申告項目を照合するための作業表です。最終選択は、App Store Connectの定義、署名付きアプリに入るSDK、その提供事業者の実際のデータ取り扱いと合わせて確定します。メールアドレス・会員識別子・会計と特典の記録を外部サービスで保持するため、「データを収集しない」という一括回答にはなりません。Firebase AuthenticationのIPログ等の根拠は[公式資料の確認記録](FIREBASE_PRIVACY_SOURCE.md)にまとめています。

| データ・処理 | 現在の実装 | Appleの分類を確認する箇所 | 利用者との関連・目的の案 |
| --- | --- | --- | --- |
| メールアドレス | Firebase Authenticationで登録・ログイン・確認メール・再設定に使用 | 連絡先情報／メールアドレス | 会員アカウントに関連付ける。Appの機能 |
| ニックネーム | 会員DBへ保存し、会員証・店舗スタッフの会員確認に表示 | 表示名が「名前」等のどの分類に当たるか定義と照合 | 会員に関連付ける。Appの機能 |
| UID・会員番号・会員ID | Firebaseと会員DB、本人・権限確認に使用 | ID／ユーザーID | 会員に関連付ける。Appの機能・不正な重複操作の防止 |
| 確認した会計金額・来店スタンプ・特典の発行／使用日時 | スタッフの確認操作により会員DBへ保存。商品ごとの購入明細は保存しない | 購入／購入履歴、必要に応じ利用状況の定義と照合 | 会員に関連付ける。Appの機能 |
| 同意した規約・方針の版、操作の記録 | 同意日時、スタッフのUID、対象・操作日時等を保存 | ユーザーID、利用状況、その他のデータのどこに含めるか照合 | 会員・スタッフに関連付く記録を含む。Appの機能・問い合わせ対応 |
| パスワード等の認証情報 | Firebaseへ送信。独自の会員DBへは保存しない | Firebase SDKの開示資料と認証情報の分類を照合 | 本人確認のために処理。「独自DBに保存しない」ことだけで申告対象外とは判断しない |
| IPアドレス・User-agent等の通信情報 | APIのアクセス制限に使用し、APIの通常リクエスト自動ログは無効。Firebase Authenticationは認証時の安全性確保・不正防止にIPアドレスとUser-agentを使用し、IPログを数週間保持すると公式資料で確認。Render・Supabase等のログ保管は未確認 | 診断・その他のデータ等のAppleの定義と照合。Firebase側での保持があるため、APIのログ無効だけで申告対象外とは判断しない | 認証・不正な大量アクセスの防止。利用者との関連付け、Apple上の分類・目的の選択は提供者の扱いと合わせて確認 |
| カメラ・会員QR | 端末でQRを読み取り、読み取った文字情報をAPIへ送信。写真・録画の保存や映像送信は実装していない | QR内の会員識別子はユーザーID関連として照合。カメラの許可と、写真・ビデオの収集を区別する | 会員確認・Appの機能 |
| 端末保存・SDKの情報 | ログイン状態、再送用の操作ID等を端末に保存。独自のIDFA取得・広告配信処理は未実装 | デバイスID、診断情報等はFirebase・Expo等の最終SDK構成と照合 | Appの機能。SDKの取り扱いを確認して最終回答 |

自社実装では、広告配信、他社のアプリやWebサイトを横断する広告追跡、広告用の分析機能を実装していません。追跡の回答はこの事実とSDK・委託先の取り扱いを合わせて決めます。位置情報を取得するAPIも使用しておらず、地図ボタンでは店舗住所をAppleの地図へ渡します。

Appleへの申告に必要な情報の確認先は、[Appのプライバシーの詳細](https://developer.apple.com/app-store/app-privacy-details/)です。この文書はAppleへの申告完了や、個人情報保護に関する適法性の認定を示すものではありません。

## 署名付きアプリができた後の撮影リスト

現時点では撮影する画面を整理しています。App Store用の画像は、署名付きの本番接続版を実際のiPhone等で開いて用意し、App Store Connectが求めるサイズに合わせます。リポジトリー内のブラウザー検証画像を、そのまま実機の掲載画像として提出する扱いにはしません。

| 順番・画面 | 写す内容 | 撮影時の確認 |
| --- | --- | --- |
| 1．ホーム | スタンプの進み具合、お店からのお知らせ | 撮影専用の会員を使い、所有者や実際のお客様の氏名・メール・番号を写さない |
| 2．お店 | 店舗住所、営業時間、基本定休日 | 個別の商品名・商品一覧を掲載しない方針を保持 |
| 3．会員証の特典条件部分 | 500円以上・1日1回・5個・90日・併用可の案内 | 下へスクロールして、実際の会員QRと会員番号が写らない位置で撮影 |
| 4．特典 | 利用できる特典と有効期限・交換条件 | 正規の条件で発行された特典がある撮影用会員で準備。表示内容や残高を画像上で作らない |
| 5．会員登録 | メールによる登録・利用規約等の案内 | 入力欄は空欄、公開文書は正式版。パスワードや確認メールのリンクを写さない |

会員QRや会員情報を含めない構成で揃えます。スタッフ管理画面は一般のお客様向けの掲載画像には含めず、必要な確認方法は審査情報欄の案内として準備します。
