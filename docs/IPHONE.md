# iPhone 確認チェックリスト

このファイルは実機で試すための手順です。**Linux の作業環境では iPhone 実機・iOS Simulator・カメラの動作を確認していません。** 以下のチェック欄は、実際に確認してから記入してください。

## 起動の準備

PC のブラウザーでデモが開けたところから、iPhone で開く手順です。**起動用 QR コードは、PC の黒い画面に `npm run start:demo -- --go --clear` を入力すると表示されます。**

この版は **Expo SDK 57** です。2026 年 10 月 25 日、利用者の iPhone に「Expo Go は SDK 57 用、プロジェクトは SDK 54」と表示されたため、PC 側のプロジェクトを更新しました。古い SDK 54 版のファイルが PC に残っている場合は、先にプロジェクトの更新が必要です。更新後の `package.json` と `package-lock.json` をそろえてから `npm ci` を実行してください。すでに SDK 57 版の部品をインストール済みなら、毎回 `npm ci` を実行する必要はありません。iPhone の Expo Go の削除や端末の初期化は不要です。

### PC と iPhone を同じネットワークにつなぐ

PC と iPhone を、自宅などの同じ Wi-Fi に接続します。PC が有線 LAN でも、iPhone の Wi-Fi と同じルーターにつながっていれば使えます。この手順では、iPhone も Wi-Fi に接続してください。

### PC：ブラウザー用サーバーを止める

`npm ci` や `npm run web` を入力した **黒い画面（コマンドプロンプト）**を開きます。ブラウザー用サーバーが動いている場合は、次の操作で止めます。

1. 黒い画面の中を一度クリックします。
2. キーボードの `Ctrl` を押しながら `C` を押します。
3. `バッチ ジョブを終了しますか (Y/N)?` と聞かれた場合だけ、`Y` を入力して `Enter` を押します。
4. `C:\Users\ユーザー名\Downloads\tamayaapp-main\tamayaapp-main>` のような、入力できる行に戻れば次へ進みます。

黒い画面を閉じてしまった場合は、キーボードの **Windows キー（窓のマーク）を押しながら R キー**を押し、小さい入力画面に `cmd` と入力して `Enter` を押します。黒い画面が開いたら、次の 1 行をコピーして `Ctrl + V` で貼り付け、`Enter` を押します。これは、今回ダウンロードしたアプリのフォルダーへ移動する命令です。

```bat
cd /d "%USERPROFILE%\Downloads\tamayaapp-main\tamayaapp-main"
```

保存先を変えた場合は、`package.json` と `README.md` が入っているフォルダーの場所に読み替えてください。すでにそのフォルダーで黒い画面を開いている場合、移動し直す必要はありません。

### PC：旧SDK 54版を更新する（今回の不一致エラーが出た場合）

PC と iPhone の Expo アカウントへのログインまで済んでいて、iPhone に「installed version は SDK 57、project は SDK 54」と表示された方向けの手順です。**同じアプリのフォルダーで、依存部品の設定ファイルを 2 つ更新します。ZIP 全体をダウンロード・展開し直す必要はありません。**

上の手順で古いサーバーを `Ctrl + C` で止め、黒い画面をアプリのフォルダーへ移動してから始めてください。以下は検証済みの SDK 57 版のファイルを指定しています。**各コード枠の 1 行だけをコピーして黒い画面に貼り付け、Enter を押します。ひとつの処理が終わってから、次へ進みます。**

1. 最初の設定ファイルを取得します。

   ```bat
   curl.exe -fL "https://raw.githubusercontent.com/iichi86/tamayaapp/430973b293e2166c14c20f9b2dd7c83d14463113/package.json" -o package.json
   ```

   転送が終わり、`C:\Users\...>` の入力行に戻るまで待ちます。`curl: (...)` というエラーが出たら、次へ進まず、その画面のスクリーンショットを共有してください。

2. もうひとつの設定ファイルを取得します。

   ```bat
   curl.exe -fL "https://raw.githubusercontent.com/iichi86/tamayaapp/430973b293e2166c14c20f9b2dd7c83d14463113/package-lock.json" -o package-lock.json
   ```

   こちらも転送が終わるまで待ちます。エラーが出たら次へ進みません。2 つのファイルを両方更新してから、部品をインストールします。

3. SDK 57 に対応する部品をインストールします。

   ```bat
   npm ci
   ```

   数分かかる場合があります。途中で別の命令を入力せず、`C:\Users\...>` の入力行に戻るまで待ちます。`npm error` が出た場合は、次へ進まず画面を共有してください。`npm warn` は警告です。最終的にエラーがなく入力行に戻ったら次へ進みます。

4. 更新したアプリを起動します。

   ```bat
   npm run start:demo -- --go --clear
   ```

   `Use port 8082 instead? (Y/n)` と聞かれたら、半角の `y` を入力して Enter を押します。**この起動で新しく表示された QR コード**を、iPhone の標準「カメラ」で読み取ります。古いサーバーの QR コードや Expo Go の古い履歴ではなく、新しい QR を使ってください。

この更新が終われば、毎回ファイルの取得や `npm ci` を繰り返す必要はありません。すでに PC と iPhone でログイン済みなら、次のログイン・インストールの項目もやり直さず、「iPhone：標準カメラで PC の QR コードを読む」へ進みます。まだログインしていない場合は、手順 4 の起動前に、次の 2 項目で PC と iPhone のログインを済ませてください。

### PC：無料の Expo アカウントでログインする

1. Expo アカウントがなければ、PC のブラウザーで [expo.dev/signup](https://expo.dev/signup) を開き、無料アカウントを作ります。これはデモアプリ内の会員登録とは別です。
2. PC の黒い画面に次を入力し、`Enter` を押します。

   ```sh
   npx expo login
   ```

3. `Email or username` または `Username/Email` を求められたら、Expo のユーザー名またはメールアドレスを入力して `Enter` を押します。
4. `Password` を求められたら、Expo のパスワードを入力して `Enter` を押します。**入力中の文字や `●` が画面に出ない場合も、そのまま入力されています。**
5. ログイン完了の表示が出たら次へ進みます。確認したい場合は `npx expo whoami` でログイン中のユーザー名を表示できます。

### iPhone：Expo Go を用意する

1. iPhone の App Store で **Expo Go** を検索してインストールします。
2. Expo Go を開き、右上のアカウントアイコン（人のマーク）を押します。「Sign in」または「Log in」を押し、**PC と同じ Expo アカウント**でログインします。

このプロジェクトは SDK 57 を使い、最低 iOS バージョンは 16.4 です。Expo Go 自体のインストール条件は、iPhone の App Store 表示も確認してください。このデモでは有料の Apple Developer Program 登録は不要です。

### PC：黒い画面に起動用 QR コードを表示する

1. PC の黒い画面に次を入力し、`Enter` を押します。

   ```sh
   npm run start:demo -- --go --clear
   ```

2. `Port 8081 is being used by another process` に続いて `Use port 8082 instead? (Y/n)` と表示された場合は、半角英数の `y` を入力して `Enter` を押します。別のポートを使って起動するための確認です。
3. 起動するまで少し待ちます。**同じ黒い画面の中に、大きな四角い QR コードが表示されます。** 通常は、`Metro waiting on exp://...` と書かれた行のすぐ上にあります。`C:\Users\...>` の入力行に戻らず、サーバーが動き続けているのが正常です。
4. ログが増えて QR コードが見えなくなった場合は、黒い画面の中を上へスクロールします。**Expo のサーバーが動いている間なら、黒い画面をクリックし、日本語入力をオフにして半角英数の `c` を 1 回押すと、QR コードを表示し直せます。`Enter` は押しません。**
5. この黒い画面は、iPhone で試している間も開いたままにします。PC の電源を入れたままにし、スリープさせないでください。

`C:\Users\...>` のようなコマンドの入力行に戻っている場合は、先に `npm run start:demo -- --go --clear` を入力して `Enter` を押します。`c` は、Expo のサーバーが動いている画面で使うキーです。

QR コードは、いま動かしている PC への接続用に、その PC で生成されます。GitHub やこの説明ページに載っている画像を読み取る手順ではありません。

### iPhone：標準カメラで PC の QR コードを読む

1. iPhone の標準の **「カメラ」アプリ**を開きます。
2. PC の黒い画面に表示された QR コードを、カメラに映します。
3. 表示された「Expo Go で開く」などのリンクをタップします。開くか確認されたら「開く」を選びます。
4. ローカルネットワークへの接続を求められたら、**許可**します。
5. 読み込み後に「むさしの玉屋」の画面が表示されれば、iPhone での起動は完了です。

ここで読むのは **アプリを起動するための QR** です。アプリ内の「会員証」に表示される **会員証 QR** は、あとでスタッフ画面から読み取るためのものです。スタッフ画面のカメラの許可は、その読み取りを開いたときに行います。

PC のブラウザーと iPhone では、デモの保存データが別です。PC で新しく作った会員や付与したスタンプは、iPhone には引き継がれません。二つの画面で会員証 QR の読み取りを試す場合は、両方の端末にある「体験用の会員」を選んでください。

### QR コードが出ない・iPhone で開けない場合

- QR コードが見つからない場合：Expo のサーバーが動いている黒い画面で、日本語入力をオフにし、半角英数の `c` を 1 回押して表示し直します。コマンドの入力行に戻っている場合は、先に `npm run start:demo -- --go --clear` を実行します。
- 黒い画面にエラーが出る、または表示し直しても QR コードが出ない場合：起動コマンドを実行した後の、**PC の黒い画面のスクリーンショット**を共有してください。表示内容から次の操作を確認できます。
- `Project is incompatible with this version of Expo Go` が出る場合：画面の SDK の数字を確認します。「installed version」は iPhone 側、「project」は PC のプロジェクト側です。「installed version は 57、project は 54」なら、古い SDK 54 版のサーバーにつながっています。PC 側のプロジェクトを更新し、古いサーバーを `Ctrl + C` で止めてから起動し直し、新しく表示された QR を読み取ってください。
- Expo アカウントのエラーが出る場合：PC の `npx expo whoami` と、iPhone の Expo Go のアカウントを確認し、同じものにそろえます。ログイン後は iPhone の「Try Again」で再試行します。
- 読み込みが進まない場合：PC と iPhone が同じルーターにつながっているか、iPhone の Expo Go にローカルネットワーク接続を許可したかを確認します。公共 Wi-Fi では、端末間の通信が禁止されている場合があります。

SDK の対応については [Expo の公式説明](https://docs.expo.dev/troubleshooting/expo-go-version-mismatch/)、アカウントについては [公式の同一アカウント要件](https://docs.expo.dev/troubleshooting/expo-go-sign-in-required/)を参照してください。更新日：2026 年 10 月 25 日。以前の SDK 54 対応という案内は今回の端末に合わなかったため、実際のエラー画面で示された SDK 57 に合わせました。**この更新だけで iPhone 実機での動作確認が済んだことにはなりません。** 以下の記録欄とチェック欄へ、実際に試してから記入してください。

## 必須の 8 項目

個人情報を入力せず、架空のニックネームで確認します。会員証・クーポンは実店舗では使えません。初期化は必要な場合だけ、確認画面を読んで確定してください。保存したデモデータが消えます。

### 1. 会員登録 → 会員証 QR

- [ ] 新規登録で架空のニックネームを入力して登録する。
- [ ] 会員番号、入力したニックネーム、会員証 QR が表示される。
- [ ] QR が画面からはみ出さず、会員証へ戻れる。
- [ ] スタッフの読み取りを開き、カメラ許可を拒否した場合の案内と戻る操作を確認する。許可後は、別の画面に表示した既存サンプル会員の QR を読める。

QR 読み取りはサーバー通信ではありません。別端末に新規登録した会員の情報は同期されません。カメラの確認には、スタッフ側にも存在する同じサンプル会員を使用します。

### 2. スタッフの付与 → お客様への反映

- [ ] 「デモ」→「店舗用に切り替える」を開き、「デモ会員を選択する」で **項目 1 で登録した新しい会員（0 個）**を指定する。この選択は、カメラでの読み取りとは別の操作である。
- [ ] 「スタンプ付与の確認へ」を開いて一度キャンセルし、スタンプが増えないことを確認する。
- [ ] 再び確認画面を開き、対象の会員情報を確認して「確認して1スタンプ付与」を押す。
- [ ] 「お客さんの画面へ戻る」で戻り、新しい会員のスタンプが 0 個から 1 個に増える。

ここでの反映は、同じ端末のローカルデータを共有しているためです。二台の端末間の同期を確認したことにはなりません。

### 3. サンプル 9 個 → 付与 → 残数 0 / 利用可能 1 枚

- [ ] 右上「デモ」で「体験用の会員（サンプル・9スタンプ開始）」を選ぶ。項目 2 でサンプル会員へ付与してしまった場合は、初期化後にこの項目から確認し直す。
- [ ] スタンプが 9 個であることを確認する。
- [ ] スタッフ画面で、その会員に本日のスタンプを付与する。「確認して1スタンプ付与」を素早く複数回押し、項目 4 の連打確認も同時に行う。
- [ ] お客様画面で、スタンプ残数が 0 個になり、新しい **100 円引きクーポンが利用可能 1 枚**になっている。
- [ ] 新しいクーポンに発行日・有効期限と 30 日間の有効期間が表示される。

初期データには、状態を見せるための「使用済み」「期限切れ」クーポンが各 1 枚あります。これらは今回発行した利用可能な 1 枚と別です。

### 4. 同じ日本時間の日・連打で重複しない

- [ ] 項目 3 と同じ会員に、同じ日本時間の日付のまま再度付与を試す。
- [ ] 「本日は付与済みです」と表示されて付与できず、スタンプ残数とクーポン枚数が増えない。
- [ ] 項目 3 の最初の確認ボタンを素早く複数回押した結果、付与が 1 回・新しいクーポンが 1 枚だけである。同日の付与後は確認画面を再度開けないため、連打は項目 3 で行う。

日付は端末時刻から日本時間（JST）に換算します。サーバー時刻や別端末間の同時操作は、このデモの保証範囲に含みません。

### 5. クーポン使用 → 使用済み・再利用不可

- [ ] お客様の「特典」で新しい未使用クーポンを開き、「店頭で提示する」→「クーポンを提示する」で特典番号を確認する。提示しただけでは未使用のままである。
- [ ] 「提示を終える」で閉じ、スタッフ画面へ切り替える。同じ特典番号の「特典利用の確認へ」を開いて一度キャンセルし、未使用のままであることを確認する。
- [ ] 再び確認画面を開き、対象会員と番号を確認して「確認して使用済みにする」を押す。
- [ ] お客様画面で「使用済み」と使用日を確認する。
- [ ] 同じクーポンを再度使用しようとしても使用できない。

### 6. 期限切れは使用できない

- [ ] 過去の見本クーポンの「期限切れ」表示と期限を確認する。
- [ ] 期限切れのクーポンを提示・使用できない。
- [ ] スタッフ画面でも、期限切れの使用を確定できない。

端末の時計を変更する必要はありません。期限切れの初期サンプルで確認します。

### 7. 再読み込み・再起動で保持する

- [ ] 登録した会員、スタンプ、クーポンの状態を控える。スタッフのお知らせも一度編集する。
- [ ] Expo Go でプロジェクトを再読み込みし、同じデータを確認する。
- [ ] Expo Go を終了して開き直し、同じプロジェクトを起動してデータが残ることを確認する。
- [ ] PC の開発サーバーを止め、`npm start` で起動し直してもデータが残る。
- [ ] デモの初期化でキャンセルしたときはデータが消えず、確定した場合だけ初期サンプルへ戻る。

Expo Go の削除、OS によるアプリデータ削除、ブラウザーの保存領域削除ではデータを失う場合があります。バックアップ機能はありません。

### 8. 小さい画面・大きい文字でも操作できる

- [ ] 小さい iPhone で、会員登録、会員証、スタンプ、クーポン、店舗情報、スタッフ画面、デモメニューを一通り開く。
- [ ] iOS「設定」→「アクセシビリティ」→「画面表示とテキストサイズ」→「さらに大きな文字」で文字を大きくし、同じ画面を確認する。
- [ ] 長いニックネーム・お知らせでも文字が切れず、横にはみ出さず、必要な部分へスクロールできる。
- [ ] キーボード表示中も入力欄・登録・保存の操作が見え、キーボードを閉じられる。
- [ ] ボタンが押しやすく、戻る・キャンセルで前の画面へ戻れる。カメラ許可拒否、未登録、クーポンなしの状態でも行き止まりにならない。
- [ ] ノッチ・画面下のホームバーに内容が重ならず、会員証 QR と確認ボタンが隠れない。
