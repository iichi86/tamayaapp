# iPhone 確認チェックリスト

このファイルは実機で試すための手順です。**Linux の作業環境では iPhone 実機・iOS Simulator・カメラの動作を確認していません。** 以下のチェック欄は、実際に確認してから記入してください。

## 起動の準備

1. [README の起動手順](../README.md#iphone-で起動する)に従い、自分の PC で `npm ci`、`npx expo login`、`npm start` を実行します。
2. iPhone に App Store 版 Expo Go をインストールします。このプロジェクトは SDK 54 です。SDK 54 の最低 iOS バージョンは 15.1 ですが、インストール条件は端末の App Store 表示も確認します。
3. PC の Expo CLI と Expo Go に **同じ無料 Expo アカウント**でログインします。PC と iPhone は同じ Wi-Fi に接続します。
4. iPhone の標準カメラで、PC のターミナルの **起動用 QR** を開きます。アプリ内の **会員証 QR** は、スタッフの読み取りに使います。
5. ローカルネットワーク接続を求められたら許可します。スタッフのカメラは、実際に読み取りを開いたときに許可します。

SDK の対応については [Expo の公式説明](https://docs.expo.dev/troubleshooting/expo-go-version-mismatch/)、アカウントについては [公式の同一アカウント要件](https://docs.expo.dev/troubleshooting/expo-go-sign-in-required/)を参照してください。確認日：2026 年 10 月 15 日（日本時間）。有料の Apple Developer Program は、この SDK 54 の App Store 版 Expo Go のデモには不要です。

## 必須の 8 項目

個人情報を入力せず、架空のニックネームで確認します。会員証・クーポンは実店舗では使えません。初期化は必要な場合だけ、確認画面を読んで確定してください。保存したデモデータが消えます。

### 1. 会員登録 → 会員証 QR

- [ ] 新規登録で架空のニックネームを入力して登録する。
- [ ] 会員番号、入力したニックネーム、会員証 QR が表示される。
- [ ] QR が画面からはみ出さず、会員証へ戻れる。
- [ ] スタッフの読み取りを開き、カメラ許可を拒否した場合の案内と戻る操作を確認する。許可後は、別の画面に表示した既存サンプル会員の QR を読める。

QR 読み取りはサーバー通信ではありません。別端末に新規登録した会員の情報は同期されません。カメラの確認には、スタッフ側にも存在する同じサンプル会員を使用します。

### 2. スタッフの付与 → お客様への反映

- [ ] 「デモ」→「店舗用に切り替える」を開き、「デモ会員を選択する」で **項目 1 で登録した新しい会員（0 個）**を指定する。この選択は、カメラでの読み取りとは別の操作である。
- [ ] 「スタンプ付与の確認へ」を開いて一度キャンセルし、スタンプが増えないことを確認する。
- [ ] 再び確認画面を開き、対象の会員情報を確認して「確認して1スタンプ付与」を押す。
- [ ] 「お客さんの画面へ戻る」で戻り、新しい会員のスタンプが 0 個から 1 個に増える。

ここでの反映は、同じ端末のローカルデータを共有しているためです。二台の端末間の同期を確認したことにはなりません。

### 3. サンプル 9 個 → 付与 → 残数 0 / 利用可能 1 枚

- [ ] 右上「デモ」で「体験用の会員（サンプル・9スタンプ開始）」を選ぶ。項目 2 でサンプル会員へ付与してしまった場合は、初期化後にこの項目から確認し直す。
- [ ] スタンプが 9 個であることを確認する。
- [ ] スタッフ画面で、その会員に本日のスタンプを付与する。「確認して1スタンプ付与」を素早く複数回押し、項目 4 の連打確認も同時に行う。
- [ ] お客様画面で、スタンプ残数が 0 個になり、新しい **100 円引きクーポンが利用可能 1 枚**になっている。
- [ ] 新しいクーポンに発行日・有効期限と 30 日間の有効期間が表示される。

初期データには、状態を見せるための「使用済み」「期限切れ」クーポンが各 1 枚あります。これらは今回発行した利用可能な 1 枚と別です。

### 4. 同じ日本時間の日・連打で重複しない

- [ ] 項目 3 と同じ会員に、同じ日本時間の日付のまま再度付与を試す。
- [ ] 「本日は付与済みです」と表示されて付与できず、スタンプ残数とクーポン枚数が増えない。
- [ ] 項目 3 の最初の確認ボタンを素早く複数回押した結果、付与が 1 回・新しいクーポンが 1 枚だけである。同日の付与後は確認画面を再度開けないため、連打は項目 3 で行う。

日付は端末時刻から日本時間（JST）に換算します。サーバー時刻や別端末間の同時操作は、このデモの保証範囲に含みません。

### 5. クーポン使用 → 使用済み・再利用不可

- [ ] お客様の「特典」で新しい未使用クーポンを開き、「店頭で提示する」→「クーポンを提示する」で特典番号を確認する。提示しただけでは未使用のままである。
- [ ] 「提示を終える」で閉じ、スタッフ画面へ切り替える。同じ特典番号の「特典利用の確認へ」を開いて一度キャンセルし、未使用のままであることを確認する。
- [ ] 再び確認画面を開き、対象会員と番号を確認して「確認して使用済みにする」を押す。
- [ ] お客様画面で「使用済み」と使用日を確認する。
- [ ] 同じクーポンを再度使用しようとしても使用できない。

### 6. 期限切れは使用できない

- [ ] 過去の見本クーポンの「期限切れ」表示と期限を確認する。
- [ ] 期限切れのクーポンを提示・使用できない。
- [ ] スタッフ画面でも、期限切れの使用を確定できない。

端末の時計を変更する必要はありません。期限切れの初期サンプルで確認します。

### 7. 再読み込み・再起動で保持する

- [ ] 登録した会員、スタンプ、クーポンの状態を控える。スタッフのお知らせも一度編集する。
- [ ] Expo Go でプロジェクトを再読み込みし、同じデータを確認する。
- [ ] Expo Go を終了して開き直し、同じプロジェクトを起動してデータが残ることを確認する。
- [ ] PC の開発サーバーを止め、`npm start` で起動し直してもデータが残る。
- [ ] デモの初期化でキャンセルしたときはデータが消えず、確定した場合だけ初期サンプルへ戻る。

Expo Go の削除、OS によるアプリデータ削除、ブラウザーの保存領域削除ではデータを失う場合があります。バックアップ機能はありません。

### 8. 小さい画面・大きい文字でも操作できる

- [ ] 小さい iPhone で、会員登録、会員証、スタンプ、クーポン、店舗情報、スタッフ画面、デモメニューを一通り開く。
- [ ] iOS「設定」→「アクセシビリティ」→「画面表示とテキストサイズ」→「さらに大きな文字」で文字を大きくし、同じ画面を確認する。
- [ ] 長いニックネーム・お知らせでも文字が切れず、横にはみ出さず、必要な部分へスクロールできる。
- [ ] キーボード表示中も入力欄・登録・保存の操作が見え、キーボードを閉じられる。
- [ ] ボタンが押しやすく、戻る・キャンセルで前の画面へ戻れる。カメラ許可拒否、未登録、クーポンなしの状態でも行き止まりにならない。
- [ ] ノッチ・画面下のホームバーに内容が重ならず、会員証 QR と確認ボタンが隠れない。
