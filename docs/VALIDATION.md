# 実行した確認と結果

更新後の確認日：2026年10月25日（日本時間）。作業環境：Linux、Node.js 24.19.0、Expo SDK 57（expo 57.0.31）、React Native 0.86.3、React 19.2.3、TypeScript 6.0.3。

利用者のiPhoneで「Expo GoはSDK 57用、プロジェクトはSDK 54」と表示されたため、依存関係をSDK 57にそろえました。以前のSDK 54対応という案内は今回の端末に合っていませんでした。アプリの画面・業務処理・保存キーは変更していません。

SDK 57への更新後、`npm ci --no-audit --no-fund`によるロックファイルからの再導入、型検査、自動テスト27件、ブラウザ全12件、iOS/Webのexportを実行し、すべて成功しました。ブラウザ全12件は単独実行で52.2秒でした。テストを同じ出力先で同時に実行しないでください。

クラウド環境の `install_script`・`start_skill` とチェックアウト位置の設定を下書き保存しました。設定の保存は新しいタスクでの復元やPublishを実行したことを意味しません。環境を再利用する際は、環境設定で内容を確認・保存してからPublishしてください。

## iOS

**iPhone実機・iOS Simulatorは、このLinux環境では利用できず、動作未検証です。** カメラ読み取り・権限、実機のキーボード、セーフエリア、iOSの大きな文字、実機でのアプリ終了後の保持は [iPhone確認手順](IPHONE.md) に沿って確認してください。Chromiumの小さい画面での確認は、SafariやiPhone実機での確認ではありません。

SDKの選択では、利用者の実際のExpo Goエラーに表示されたSDK 57を優先しました。SDK 57の公式npm配布物の互換定義と、公式TypeScriptテンプレートの依存バージョンを使用しています。`latest`は別のSDKになる可能性があるため使用していません。更新後に実機でアプリを開けるかどうかは未確認です。PCとExpo Goには同じ無料Expoアカウントでログインします。

ブラウザ版にはカメラ読み取りを含めていません。「デモ会員を選択する」で一連の受付操作を試せます。ネイティブ版のカメラ処理は別ファイルに実装しています。
