## 3．PC側のビルド用ファイルを更新する

ZIPで使っているWindows側へ、ビルドに渡すファイルの整理とNodeの指定を反映できます。アプリ直下の黒い画面で次を1行ずつ実行します。

```bat
cd /d "%USERPROFILE%\Downloads\tamaya-server-setup\tamayaapp-main"
```

```bat
curl.exe -fL --retry 3 "https://raw.githubusercontent.com/iichi86/tamayaapp/84c1af5afdeadc199e0bd905d1926d4b25cb6106/.easignore" -o .easignore
```

```bat
curl.exe -fL --retry 3 "https://raw.githubusercontent.com/iichi86/tamayaapp/84c1af5afdeadc199e0bd905d1926d4b25cb6106/eas.json" -o eas.json
```

取得エラーが出た場合は、その表示を確認してから続けます。この2ファイルに加えて、登録済みBundle IDをアプリの設定とPC・EASの環境変数へそろえます。署名付きビルドは、これらの設定と公開文書の確認後に行います。

## 4．掲載名・アイコンを確認する

掲載名の案は「むさしの玉屋」、現在のアイコンは[深緑と「玉」のデザイン](../assets/app-icon.png)です。[掲載文案](STORE_LISTING.md)を読み、変更希望があれば確定します。正式な店舗ロゴを使う場合は、使用できる素材を用意します。

App Store用の実機スクリーンショットは、署名付きアプリが完成した後に撮影します。今は撮影する画面と文章を準備する段階です。

## 5．バックアップの運用を選ぶ

手動取得の手順は準備済みです。自動取得を選ぶ場合、Supabase Proは基本月額25米ドルで、直近7日分の日次バックアップが含まれます。税・為替・追加利用分は公式の契約画面で確認します。毎日正常に取得できても、直近の取得から後の最大約1日分は含まれない可能性があります。

有料契約はまだ選択・実行していません。実際のお客様の会員運用を始める前に、取得担当、保存先、日次取得、復元手順を決めます。保管7日分は手動運用の提案で、採用済みの規則ではありません。
