## 完了した段階1・2の一括操作（参照用）

以下は今回実行した操作の記録です。再実行は不要です。

Windowsキーを押しながらRを押し、`cmd`と入力してEnterを押します。黒い画面で次の1行を実行します。

```bat
cd /d "%USERPROFILE%\Downloads\tamaya-server-setup\tamayaapp-main" && curl.exe -fL --retry 3 "https://raw.githubusercontent.com/iichi86/tamayaapp/e81bd799185aa00585cedab95a198d0646e4ee6f/scripts/prepare-ios-build.mjs" -o "scripts\prepare-ios-build.mjs" && node scripts\prepare-ios-build.mjs --build --submit
```

このコマンドは、用意した準備スクリプトを取得して実行します。スクリプトの内部では検証済みコミットのファイルを取得し、内容のハッシュが一致してから更新します。既存の接続設定を保持し、今回承認された設定を更新して、チェックとビルドへ進みます。ビルド成功後はTestFlightへのアップロードも自動で進めます。ダウンロードや確認に失敗した場合はエラーを表示して止まります。

Appleのログイン・認証コード・アップロード用の鍵等を求められたら、ご本人が黒い画面で対応します。質問の意味が分からない場合は、その画面を送ってください。ビルドが始まった場合は、表示されたExpoのビルド画面で状況を確認します。ビルド・アップロードの結果を確認してから、iPhoneへTestFlight版を入れる操作を案内します。

この一括操作は、段階1のビルドと段階2のアップロードを対象にします。App Reviewへの審査提出と一般公開は、実機・掲載情報の準備を終えた後の段階です。`--submit`を省いた`--build`のみの指定ではビルドまで、`--local-only`ではローカルの更新・チェックまでを実行できます。

### 実機確認と公開時の運用

すでにExpo Goで確認した全操作を、理由なく最初から繰り返す手順にはしません。署名付きアプリの起動・ログイン・会員情報・QR等、配布版で確認する必要がある要点に絞ります。掲載画像には実際の署名付きアプリの画面を使います。本番の残高・日付を作り替えたり、5日間待つことを作業全体の条件にしたりしません。
