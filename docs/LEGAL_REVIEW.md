## 利用規約の文案

むさしの玉屋 会員サービス利用規約

本サービスはワンエイトが運営する、むさしの玉屋の会員サービスです。お客様の会員登録、会員証、スタンプ・特典機能の利用料は無料です。通信に必要な費用はお客様の負担となります。

ご本人が管理するメールアドレスで登録し、確認メールの手続きを行ってください。メールアドレスとパスワードはご本人が管理してください。機種変更後も、同じメールアドレスとパスワードで会員情報を利用できます。パスワードを忘れた場合は、登録メールアドレスで再設定できます。

生菓子・ギフト商品がスタンプの対象です。500円以上のお会計のある来店について、店舗スタッフが確認して1スタンプを付与します。同じ会員への付与は日本時間で1日1回までです。

5スタンプに達すると5個を消費し、生菓子1つと交換できる特典を1枚発行します。当日の対象となる生菓子からスタッフが1つ選んでお渡しします。アプリで商品を抽選する仕組みではありません。特典の有効期間は発行から90日間です。交換時に追加購入は必要なく、他の割引・クーポンとの併用ができます。使用済み・期限切れの特典は使えません。発行済みの特典は発行時の条件で取り扱います。

スタンプ付与と特典の使用は、店舗スタッフが来店・会計・会員情報を確認して行います。会員QRコードを読み取っただけではスタンプは付きません。スタンプ・特典の換金や他の会員への譲渡、不正利用はできません。通信障害等により処理を確認できない場合は、店舗スタッフまたは問い合わせ窓口へご連絡ください。

アプリの「設定」から退会・アカウント削除を申請できます。本人確認のため、現在のパスワードを入力します。退会によりスタンプ・未使用の特典は失効します。スタッフ権限がある方は、先にオーナーが権限を停止します。登録メールを利用できない場合等の本人確認は、問い合わせ窓口でご相談ください。

重要なお知らせや利用条件の変更はアプリ内で案内します。会員サービスへのお問い合わせは、ワンエイト（080-4909-7012）で受け付けます。店舗の商品・営業時間等のお問い合わせ先は、むさしの玉屋（03-3381-7012）です。

## プライバシーポリシーの文案

むさしの玉屋 会員サービス プライバシーポリシー

ワンエイトは、本サービスで取り扱う情報を、会員の本人確認、会員証の表示、来店スタンプ・特典の管理、操作の重複や不正利用の防止、お問い合わせ対応のために利用します。

登録メールアドレス、ログイン用の識別子、認証情報は、GoogleのFirebase Authenticationで取り扱います。本サービス独自の会員データベースへ、メールアドレスやパスワードを保存する仕組みではありません。

会員データベースには、ログイン用の識別子、ニックネーム、会員番号、スタンプ残高、登録日時、スタンプの付与日時、スタッフが確認した会計金額、特典の発行・使用履歴、同意した規約・方針の版と日時、スタッフ権限や操作の記録を保存します。

不正な大量アクセスを防ぐため、IPアドレス等の通信情報を処理します。Firebase Authenticationも、登録・認証時の安全性確保と不正利用の防止のため、IPアドレスとユーザーエージェント（端末・ソフトウェア等の情報）を処理します。

サービスの提供に次の外部サービスを利用します。

| サービス | 用途・現在確認できている地域 |
| --- | --- |
| Google Firebase Authentication | 登録・ログイン・メール確認・パスワード再設定。公式資料では米国のデータセンターで稼働し、米国内で処理 |
| Supabase PostgreSQL | 会員・スタッフ権限・スタンプ・特典等のデータ。所有者の設定画面で韓国・ソウルを確認 |
| Render | 管理サーバーの稼働。所有者の設定画面で米国・オハイオを確認 |

ログイン状態を維持する情報と、通信結果が不明な操作を重複させず再試行するための情報を、お使いの端末にも保存します。

カメラは、店舗スタッフが会員QRコードを読み取るために使用します。読み取ったQRの文字情報を管理サーバーへ送り、会員を確認します。写真・録画を保存したり、カメラの映像を送信したりする機能は実装していません。広告識別子による追跡や広告配信の機能も実装していません。

会員情報は、退会するまで保管します。長期間の未利用を理由に会員を自動削除する運用は行いません。

退会操作では本人確認後に会員機能を停止し、認証アカウントと会員情報の削除処理を進めます。外部サービスとの通信に失敗した場合は、サーバーの稼働中に再試行します。削除処理が完了していない場合は、処理中として案内します。

Googleの公式説明では、Firebase AuthenticationのIPログは数週間保存されます。その他の認証情報は、運営者によるFirebase上の対象ユーザーの削除開始まで保持され、その後180日以内に稼働中のシステムとバックアップから削除されます。この期間は、アプリでのアカウント利用停止や、次に説明する業務記録の90日削除とは別の、Firebase側のデータ削除に関するものです。

会員情報の削除後も、会員情報との参照を外した利用・操作の記録が一時的に残ります。これには日時、会計金額、特典番号等が含まれます。退会後に会員への参照がなくなったスタンプ・特典・退会した会員に関する操作記録は、記録の発生から90日経過後、サーバー稼働中の定期処理で順次削除します。退会処理の完了記録は、処理完了から90日経過後に削除対象とします。現在の会員に結び付く履歴と、未完了の退会処理はこの期限削除の対象にしません。

Supabase・Render側のバックアップやログの保存期間と、独自に取得するバックアップの保管・復元時に退会済み情報を再利用しないための扱いは、実際の設定と照合する必要があります。DB内の90日削除と、別に取得したバックアップの削除は同じ処理ではありません。

情報の開示・訂正・削除や取り扱いに関するお問い合わせは、ワンエイト（080-4909-7012）へご連絡ください。本人確認のうえ対応します。運営者の氏名・住所等の必要な事業者情報についても、ご本人のお問い合わせに応じて上記窓口から個別に案内します。

- **退会後の記録**：所有者が11月2日に、記録の発生から90日経過後に削除する仕組みの追加を選択しました。対象は退会によって会員との紐付けが外れた記録です。サーバー起動時・稼働中の原則1時間ごとの処理で、各種類を1回最大1,000件ずつ削除します。休止・障害・未完了の処理等により削除の完了時刻は遅れる場合があります。通常の会員履歴を90日で失効させる規則ではありません。
- **バックアップと提供事業者のログ**：Firebase AuthenticationのIPログと認証情報の期間は公式資料で確認しました。Supabase・Render側の保存・削除期限、独自バックアップの取得方法・保管期間、復元後に退会済みの情報を利用しない手順は確認事項です。退会時に全バックアップから即時消去されるとは記載しません。
- **国外での取り扱い**：Firebase Authenticationの米国内処理は公式資料、SupabaseとRenderの設定地域は所有者の画面に基づく情報です。これらの資料だけで実アカウントの契約条件全体を確認したとは扱わず、必要な利用者への案内と合わせて確認します。
- **適用と同意**：正式な規約・方針の版と適用日を決め、既存の確認用文面へ同意した会員への案内・同意記録の扱いを整理します。確認事項が残る間は、リリース承認フラグを有効にしません。

## 提供事業者の資料で確認できたこと

2026年11月2日、[Supabase公式のDatabase Backupsの公開ソース](https://raw.githubusercontent.com/supabase/supabase/master/apps/docs/content/guides/platform/backups.mdx)を取得しました。自動日次バックアップの対象はPro・Team・Enterpriseで、Freeについては定期的なCLIの`db dump`と別の保存先での保管を推奨しています。Freeで自動日次バックアップを利用できるとは記載しません。実アカウントの取得状況・保管期間・復元は未確認です。カスタムDBロールのパスワードはバックアップに含まれないため、復元時の再設定も必要です。

2026年11月3日、所有者が公式URLから取得して添付した[Firebaseのプライバシー資料](https://firebase.google.com/support/privacy)のHTML本文を確認しました。Firebase Authenticationは米国のデータセンターで稼働し米国内のみで処理、IPログは数週間、その他の認証情報は対象ユーザーの削除開始後180日以内に稼働中のシステムとバックアップから削除するとの説明です。根拠となる原文・見出し・資料の識別情報を[Firebase資料の確認記録](FIREBASE_PRIVACY_SOURCE.md)へ残しました。ユーザー削除が外部通信の失敗等で未実行の状態を、Firebase側の削除開始と同一視しません。

このFirebaseの資料は、Supabase・Render側のログやバックアップの保管期間を説明するものではありません。これらの未確認の期間を推測で埋めず、実際の運用と照合します。

バックアップの具体的な取得・復元方法は[バックアップ手順](BACKUP_RESTORE.md)、App Storeの説明文と申告の整理は[掲載準備案](STORE_LISTING.md)へまとめています。
