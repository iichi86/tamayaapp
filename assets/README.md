# アプリアイコン

`app-icon.png` は、2026年11月4日に所有者が提供した店舗の正式ロゴを基に用意した、生成りの背景と赤い店印のアイコン用画像です。元の生成画像は1254×1254・不透明PNGで、画像生成ツールでアイコン用に整えたものを使用しています。

Expo SDK 58の実際のiOSアイコン生成処理で、1024×1024・全画素不透明のApp Iconを生成できることを確認しました。角の形はiOS側で適用されるため、画像自体は四角のままです。アプリ設定の`icon`はこのファイルを参照します。

以前の深緑と「玉」の文字の仮デザインは置き換えました。今回のロゴ用画像に追加の文字や商品写真は入れていません。
